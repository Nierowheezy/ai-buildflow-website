An optional global installation exposes short read-only status and local dashboard commands:

```bash
npm install --global create-ai-buildflow@latest
```

| Command | Purpose |
| --- | --- |
| `buildflow status` | Project status and suggested next action |
| `buildflow dashboard` | Live read-only local dashboard |

## Requirements

- Node.js 22 or newer.
- Run inside a project that has BuildFlow installed.

## npx forms

The same status and update commands are available without a global install:

```bash
npx create-ai-buildflow@latest status
npx create-ai-buildflow@latest update --dry-run
npx create-ai-buildflow@latest update
```

## Boundaries

The dashboard binds to `127.0.0.1`, reads the same project files and Git state, and stops when you press Ctrl+C. It does not run workflow commands or expose the project outside the local machine.
